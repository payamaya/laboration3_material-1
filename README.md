# Laboration 3 - Norrgläntan
Detta är en responsiv startsida för den fiktiva natur destinationen Norrgläntan, skapad som en del av kursen **DT224G**.<br>
Projektet är byggt utifrån en given wireframe och en egenutvecklad Figma-mockup, med fokus på semantisk `HTML`, mobile-first design och `CSS` Flexbox/Grid.

---
## Teknik & Metod
- **HTML5**: Semantiska element (`<header>`, `<main>`, `<section>`, `<article>`,` <footer>`).
- **CSS3**: Mobile-first layout med Media Queries samt Flexbox.
- **Versionshantering**: Git och GitHub med en stegvis och tydlig commit-historik.
- **Tillgänglighet**: Följer grundläggande principer (kontraster, alt-texter på bilder, logisk rubrik struktur).
